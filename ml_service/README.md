# IntelliHeart ML Microservice

Python микросервис для классификации интентов голоса на основе обученной нейросети.

## Структура

```
ml_service/
├── main.py              # FastAPI приложение
├── requirements.txt     # Зависимости Python
└── README.md           # Документация (этот файл)
```

## Установка

### Требования

- Python 3.8+
- pip

### Шаги установки

1. Перейти в папку сервиса:
```bash
cd ml_service
```

2. Установить зависимости:
```bash
pip install -r requirements.txt
```

3. Убедитесь, что модели `intent_model.pkl` и `vectorizer.pkl` находятся в корне проекта (папка `damumed/`).

## Запуск

Запуск сервера на порту 8000:
```bash
python main.py
```

Или через uvicorn:
```bash
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

## API Эндпоинты

### GET /health
Проверка здоровья сервиса

**Ответ:**
```json
{
  "status": "healthy",
  "service": "IntelliHeart ML Service",
  "version": "1.0.0"
}
```

### POST /predict
Предсказание интента на основе текста

**Запрос:**
```json
{
  "text": "Дәрігерге жазылу керек"
}
```

**Ответ:**
```json
{
  "text": "Дәрігерге жазылу бөліміне өтудеміз.",
  "action": "NAVIGATE_TO_APPOINTMENT"
}
```

### Поддерживаемые интенты

| Интент | Ответ | Действие |
|--------|-------|----------|
| Запись к врачу | "Дәрігерге жазылу бөліміне өтудеміз." | `NAVIGATE_TO_APPOINTMENT` |
| Медкарта | "Медициналық картаңызды ашып жатырмын." | `NAVIGATE_TO_RECORDS` |
| Вызов врача | "Дәрігерді үйге шақыру формасы." | `CALL_DOCTOR` |
| Профиль | "Сіздің жеке кабинетке өтіп барамын." | `NAVIGATE_TO_PROFILE` |
| Неизвестно | "Кешіріңіз, мен сізді түсінбедім." | `NONE` |

### POST /batch_predict
Пакетное предсказание для множества текстов

**Запрос:**
```json
[
  {"text": "Жазылу"},
  {"text": "Медкарта"}
]
```

**Ответ:**
```json
[
  {"text": "Дәрігерге жазылу бөліміне өтудеміз.", "action": "NAVIGATE_TO_APPOINTMENT"},
  {"text": "Медициналық картаңызды ашып жатырмын.", "action": "NAVIGATE_TO_RECORDS"}
]
```

### GET /docs
Интерактивная документация API (Swagger UI)

Доступна по адресу: `http://localhost:8000/docs`

## Интеграция с Spring Boot бэкендом

Бэкенд обращается к этому микросервису через:

```
POST http://localhost:8000/predict
```

Конфигурация находится в `backend/src/main/resources/application.yml`:

```yaml
ml:
  service:
    url: http://localhost:8000
```

## Логирование

Логирование настроено на уровне INFO. Все события загрузки модели и предсказаний логируются.

## Ошибки

| Код | Описание |
|-----|----------|
| 200 | Успешное предсказание |
| 400 | Текст не может быть пустым |
| 503 | Модель еще не загружена |
| 500 | Ошибка при обработке |

## Модели

Сервис использует две предварительно обученные модели:

- **intent_model.pkl** - Классификатор интентов (scikit-learn)
- **vectorizer.pkl** - TfidfVectorizer для преобразования текста

## Производительность

- Время загрузки модели при старте: ~2 сек
- Время предсказания на одном примере: ~10-50 мс
- Размер моделей: ~5 МБ

## Безопасность

- Входная валидация через Pydantic
- Обработка исключений на всех эндпоинтах
- Логирование всех ошибок
