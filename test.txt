Инструкция полной проверки работоспособности IntelliHeart

1) Запуск инфраструктуры (PostgreSQL + backend + ml_service)
   - В корне репозитория:
     docker compose up --build
   - Убедитесь, что контейнеры подняты:
     docker ps

2) Проверка доступности сервисов
   - ML сервис:
     http://localhost:8000/health  (должно вернуть status: healthy)
   - Backend:
     http://localhost:8080/swagger-ui/index.html

3) Проверка авторизации (email/пароль)
   - Регистрация:
     curl -X POST http://localhost:8080/api/auth/register ^
       -H "Content-Type: application/json" ^
       -d "{\"email\":\"test@example.com\",\"password\":\"secret\"}"
   - Логин:
     curl -X POST http://localhost:8080/api/auth/login ^
       -H "Content-Type: application/json" ^
       -d "{\"email\":\"test@example.com\",\"password\":\"secret\"}"
   - Запомните userId из ответа (нужен для уведомлений).

4) Добавление врача и проверка списка
   - Если врач уже есть (демо-сид), шаг создания можно пропустить.
   - Создать врача:
     curl -X POST http://localhost:8080/api/doctors ^
       -H "Content-Type: application/json" ^
       -d "{\"fullName\":\"Айдын Серікұлы\",\"specialization\":\"Кардиолог\",\"qualification\":\"Жоғары санат\",\"experienceYears\":12,\"licenseNumber\":\"KZ-CRD-001\",\"phoneNumber\":\"+77010000000\",\"email\":\"aidyn@clinic.kz\",\"workplace\":\"Damumed Clinic\"}"
   - Получить список:
     curl http://localhost:8080/api/doctors

5) Проверка голосового помощника (backend)
   - Запрос:
     curl -X POST http://localhost:8080/api/assistant/query ^
       -H "Content-Type: application/json" ^
       -d "{\"text\":\"Запиши меня к врачу\"}"

6) Проверка уведомлений (backend API)
   - Создать уведомление:
     curl -X POST http://localhost:8080/api/notifications ^
       -H "Content-Type: application/json" ^
       -d "{\"title\":\"IntelliHeart\",\"message\":\"Тесттік хабарлама\",\"userId\":1}"
   - Получить список:
     curl http://localhost:8080/api/notifications?userId=1

7) Запуск Android-приложения
   - Открыть frontend/ в Android Studio.
   - Для эмулятора оставить BASE_URL = http://10.0.2.2:8080/
     Для физического устройства указать IP ПК.
   - Запустить приложение.

8) Проверка функционала в приложении
   - Войти/зарегистрироваться (email+пароль).
   - Открыть вкладку "Уведомления":
     * Нажать "Тесттік уведомление жіберу".
     * Дать разрешение на уведомления (Android 13+).
     * Убедиться, что пришло системное уведомление и запись появилась в списке.
   - Открыть "Запись к врачу", выбрать врача и заполнить профиль пациента (если запрашивается).
     * Ввести ИИН, ФИО, дату рождения, пол, телефон и адрес.
     * Сохранить профиль пациента.
     * Указать дату/время приема и отправить заявку.
   - Открыть "Запись к врачу" — врач должен отображаться.
   - Нажать микрофон и произнести фразы:
     * "Запиши меня к врачу"
     * "Покажи медкарту"
     * "Открой профиль"

9) Логи при проблемах
   - Backend:
     docker logs intelliheart-backend
   - ML:
     docker logs intelliheart-ml
   - Postgres:
     docker logs intelliheart-postgres
