# AGENT_CONTEXT.md - Медицинский Голосовой Помощник DAMUMED

## 1. Текущее состояние репозитория

**Статус:** Репозиторий инициализирован, основные структуры еще не созданы.

**Описание проекта:** Мобильное приложение интеллектуального медицинского голосового помощника для казахстанского рынка.

**Архитектура:**
- **Backend:** Spring Boot (Java)
- **Frontend:** Android Studio (Kotlin)

## 2. Технические требования и сущности (на основе ТЗ)

### Backend сущности (Spring Boot):
- **User** - Пользователи приложения (пациенты и врачи)
- **Patient** - Профиль пациента с историей болезни
- **Doctor** - Профиль врача (специальность, квалификация)
- **Appointment** - Запись на прием к врачу
- **MedicalRecord** - Медицинская карта пациента
- **VoiceSession** - Сессия голосового взаимодействия
- **VoiceMessage** - Голосовые сообщения (запись и транскрипция)
- **Diagnosis** - Результаты диагностики от голосового помощника
- **Prescription** - Рецепты и назначения
- **Notification** - Уведомления для пациентов и врачей

### Frontend компоненты (Android/Kotlin):
- **AuthFragment** - Авторизация и регистрация
- **HomeFragment** - Главный экран с быстрыми действиями
- **VoiceAssistantFragment** - Интерфейс голосового помощника
- **AppointmentFragment** - Запись на прием
- **MedicalRecordFragment** - Просмотр медицинской карты
- **DoctorListFragment** - Список врачей
- **ProfileFragment** - Профиль пользователя
- **NotificationsFragment** - Центр уведомлений

## 7. Безопасность и конфиденциальность

- **HIPAA/GDPR соответствие:** Все медицинские данные должны быть зашифрованы
- **Аутентификация:** JWT токены с refresh механизмом
- **Авторизация:** Role-based access control (RBAC)
- **Данные пациентов:** Должны быть защищены и доступны только пациенту и его врачам
- **Голосовые записи:** Должны быть удалены после обработки или в соответствии с политикой
