🏗️ АРХИТЕКТУРА
═════════════════════════════════════════════════════════════════════════════

  BACKEND ARCHITECTURE:
    Controllers → Services → Repositories → Database
    (REST API)   (Logic)    (JPA/SQL)     (H2/PostgreSQL)

  FRONTEND ARCHITECTURE:
    UI (Compose) → ViewModel (State) → Network (Retrofit)
                                    → Voice (STT/TTS)

  VOICE ASSISTANT FLOW:
    User speaks → SpeechRecognizer → Send to API → NLP analysis
      ↓
    Get response → TextToSpeech → Play audio → Navigate (if needed)
